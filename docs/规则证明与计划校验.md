# ASK PASS 规则证明与执行计划校验

<a id="plan-proof"></a>

## 1. 准备计划时求证

`ASK::Pass` 是 ASK 的静态库，接口与实现位于 `lib/Pass/`，规则位于 [`rules/pass/`](../rules/pass/)。它直接使用 [Rin](../../rin/README.md) 的 C++ 头文件接口。ASK 维护执行计划与显存槽位的领域规则，Rin 提供通用推理和整数比较。

`Session::prepareProgram` 核对步骤索引、单一生产者、端口绑定和 kernel ABI，生成内部缓冲区的槽位映射，再调用 `checkAllocationPlan`。该接口检查映射完整性，向 Rin 提交结构化事实和证明目标：

| 目标 | 原始事实 | 规则 |
| --- | --- | --- |
| 每次读取和公开输出可用 | 缓冲区的产生边界、使用边界 | `产生边界 <= 使用边界` |
| 槽位容量足够 | 缓冲区字节数、槽位容量 | `字节数 <= 容量` |
| 同槽生存期分离 | 槽位归属、产生步骤、最后使用步骤 | 相邻缓冲区满足 `前者最后使用 < 后者产生` |

公开输入的产生边界为 `0`，步骤 `i` 的输出产生于边界 `i + 1`。读取在对应步骤前发生，公开输出在最终边界可用。规则见 [`plan_availability.rin`](../rules/pass/plan_availability.rin) 和 [`allocation_plan.rin`](../rules/pass/allocation_plan.rin)。数字以 `uint64` 事实传递，比较由 Rin 的 `less` / `less_equal` 求值。

证明在 Session 锁外执行，通过后创建不可变 `PreparedProgram`。`Fail`、`Unknown` 和 `Error` 分别报告目标未证成、推理达到上限、规则或输入错误，准备接口抛出包含相应诊断的 `CUDAError`。

<a id="reuse-boundary"></a>

## 2. 槽位分配与执行

ASK 按生产步骤遍历内部缓冲区，优先选择生存期已结束的槽位，槽位容量取其所有缓冲区字节数的最大值。公开输入输出使用独立存储。同一步骤中的输入和输出保持不同槽位。

`checkAllocationPlan` 检查每个内部缓冲区恰好分配一次、槽位索引有效、每个槽位有使用者。它将各槽位的缓冲区按生产步骤排序，并求证每一对相邻生存期严格分离；这一条件也保证该槽位内任意两个生存期分离。

每个在途提交持有独立工作区，每个槽位对应一个 `DeviceBuffer`。完成事件保留工作区，完成后复用。准备阶段将参数分类为冻结值、内部地址和公开端口地址；工作区创建时写入冻结值和内部地址，每次提交更新公开端口地址。执行循环直接使用已准备的参数和启动描述。

kernel 生产者须遵守声明的端口契约：读取 `inputs`、写入 `outputs`，访问限制在声明缓冲区内，端口地址的使用随该步骤完成而结束。运行时通过单 stream 顺序提交，或串联 CUDA Graph 节点，维持步骤顺序。

槽位分配降低内部显存需求，证明器确认候选映射合法。图级常量折叠、DCE、融合分组与步骤切分由 ASK 的编译优化模块完成，见[图优化](图优化与自有代码生成.md#graph-passes)。

<a id="proof-cache"></a>

## 3. 规则与证明缓存

ASK 在进程内创建一个不可变 Rin `Program`，规则解析一次。每次新证明通过 `Fact` 和 `Obligation` 传入数值事实与目标。

成功结果保存在有界的进程缓存中。键包含完整计划结构、各序列长度、缓冲区大小、槽位容量和全部分配项，按完整值比较。相同计划再次准备时复用成功结果；缓存最多保存 64 个键，键内容的累计长度上限为 65,536 个 `size_t` 元素，并按写入顺序淘汰。

缓存查询和规则求证都发生在计划准备阶段。`PreparedProgram` 执行时复用已确定的映射和参数；每次传入的公开缓冲区在提交入口检查设备、大小、可写性与别名。

<a id="build-dependency"></a>

## 4. 构建依赖

`cmake/rin.lock.json` 固定 Rin 仓库和提交。CMake 通过 `FetchContent` 获取 `Rin::Pass` 头文件目标；ASK 的 `ASK::Pass` 编译本仓规则和通用证明器，`ASK::Runtime` 吸收该静态库。安装包使用者链接 ASK SDK。

本地开发时指定 Rin 源码目录：

```bash
cmake --preset core -DASK_RIN_SOURCE_DIR=/path/to/rin
cmake --build --preset core
```
